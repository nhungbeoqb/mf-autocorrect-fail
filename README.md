One line, under 200 characters, that reads as a funny autocorrect fail and nothing else: a text to the boss meant to say "I quit" comes out as "I quilt", and HR replies that they look forward to the blanket.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt`.
